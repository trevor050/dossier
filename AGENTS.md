# AGENTS.md

Self-hosted person-level analytics. Package `@trevor050/dossier` (not yet on npm). Canonical consumer: `trevor050/colgate-room-portfolio` (pixi canvas site; uses `enter/leave` for overlays, `sections: false`).

## Layout
- `src/client/` tracker (`initDossier`), `clock.ts` (ActivityClock, DwellCounter: pure, tested), `privacy.ts`.
- `src/chunks/` esbuild-only entries (tracker IIFE, rrweb recorder, fingerprint). Excluded from tsc build.
- `src/server/` Web `Request→Response` handlers: `collect.ts` (GET = tracker script/`?asset=`, POST events, POST `?kind=replay`), `admin/handler.ts` (HTML + `?api=` JSON + `?asset=`). `node.ts` adapts to node:http. `vercel/*.ts` = `export default { fetch }`.
- `src/server/migrations.ts` append-only list. Never edit a shipped migration; add one. Runtime never runs DDL; `assertSchemaReady` caches per Db.
- `src/generated/*.ts` and `dashboard/world.gen.ts` are generated by `scripts/build-assets.mjs` (gitignored). typecheck/test run it with `--if-missing`; run `npm run build:assets` after editing client/dashboard code or tests use stale bundles.
- `dashboard/` Preact app, bundled into `ADMIN_ASSETS`. Types imported from server modules (type-only).
- `src/demo/` seed + sample site for `dossier demo`. All names/networks invented (AS0000 Example ...). Keep it that way.

## Commands
- `npm run build` (assets → tsc → postbuild version check). `npm test` (vitest, PGlite integration). `npm run typecheck`.
- `npm run demo` → localhost:8787 (`/api/admin`, sample site at `/`).
- `node scripts/e2e.mjs` (needs a server with sample site; `TOKEN=` for non-demo). `node scripts/screenshots.mjs docs/screenshots` (needs demo running). Both use `playwright-core@1.65.0` = cached chromium-1254; bumping it needs a matching browser download.
- Local PG used for verification: `initdb .local/pg`, `pg_ctl -D .local/pg -o "-p 54329 -k $PWD/.local" start`.

## Hazards
- Node 20 locally → vitest pinned to 4.x (5.x needs Node 22). esbuild target must stay `safari15`+ (safari13/14 targets fail on destructuring).
- PGlite needs explicit casts on ambiguous params (`$3::int`); a type error in collect is swallowed as 204, so check logs / tests when something silently doesn't store.
- Headless Chromium beacons carry `HeadlessChrome` UA even with context UA override; that correctly flags sessions as bots. e2e flushes + `optOut()` before navigating away.
- `is_bot` is sticky (OR) per session unless `visitors.bot_override` is set.
- Admin cookie Path = request pathname (`/api/admin`). Mount path agnostic; dashboard uses `location.pathname` as API base.
- Tracker must not write storage before privacy checks (tested).
- Session timing source of truth = `session_pages` (one row per page load, highest `seq` wins, rolled up on read by `rollup.ts`). `sessions.active_seconds/sections/pages` are only a cache refreshed on write. Never add to running totals. No pageview id ⇒ `_legacy` key (last write wins, ordered by session_seconds).
- Clicks: count via `admin/actions.ts` (`collapseActions`), never `COUNT(*)` over events; one action can be click_target+open_overlay or click_target+click_link.
